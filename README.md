# Sioux City, Iowa — Timeline

A web-ready HTML timeline of significant events in the history of Sioux City, Iowa, from prehistoric habitation through the present day.

## View

Open `index.html` in a browser, or visit the GitHub Pages URL once Pages is enabled in repo settings.

## Contents

- `index.html` — self-contained single-page timeline (inline CSS, no external dependencies).
- `LICENSE` — MIT License.

## Source data

See the "Sources" section at the bottom of `index.html` for the references used to compile the timeline.
